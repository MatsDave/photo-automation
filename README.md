# Photo Automation Backend

Telegram-to-social-media publishing automation for Himalayan Meditation NZ - Guruttattva.

Send or forward a photo to your private Telegram bot, receive an AI caption draft generated by Gemini, review/edit the draft with interactive Telegram buttons, and publish upon approval to:
- **Instagram** (Professional/Creator account)
- **Facebook Page**
- **Threads**

## Features

- 📸 **Telegram intake & interactive preview**: Send a photo to receive a caption draft with **Approve & publish**, **Edit caption**, **Regenerate**, and **Cancel** buttons.
- 🤖 **Gemini AI captioning**: Generates quote-first captions with clean formatting and relevant hashtags.
- 📱 **Multi-platform publishing**: Publishes simultaneously to all connected Meta platforms (Instagram, Facebook Page, Threads) with individual status reporting.
- 🔐 **Zero-disk credential persistence**: Tokens are encrypted with Fernet and can be injected as environment variables (`INSTAGRAM_TOKEN_ENCRYPTED`, `FACEBOOK_TOKEN_ENCRYPTED`, `THREADS_TOKEN_ENCRYPTED`) for diskless/free hosting.
- 🔄 **Token auto-renewal**: `/auth/refresh` endpoint and CLI script `scripts/refresh_tokens.py` to refresh 60-day Instagram and Threads tokens.
- 🧹 **Ephemeral media lifecycle**: Automatically cleans up temporary media after publication and prunes stale files on startup.
- ☁️ **Render Free deployment**: Built and configured for Render Free hosting with no paid database or persistent disk needed (see [RENDER_FREE_SETUP.md](RENDER_FREE_SETUP.md)).

## Quick Start (Local Development)

1. **Create and activate a virtual environment**:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **Install dependencies**:
   ```powershell
   python -m pip install -r requirements.txt
   ```

3. **Configure environment**:
   Copy `.env.example` to `.env` and generate secrets:
   ```powershell
   python -c "import secrets; print(secrets.token_urlsafe(48))"
   python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```

4. **Run tests**:
   ```powershell
   python -m unittest discover -s tests -v
   ```

5. **Start local service**:
   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

6. **Connect social accounts**:
   Expose port 8000 via Cloudflare Tunnel or ngrok, update redirect URIs in Meta developer settings, and visit:
   - Instagram: `http://127.0.0.1:8000/auth/instagram/connect`
   - Facebook Page: `http://127.0.0.1:8000/auth/facebook/connect`
   - Threads: `http://127.0.0.1:8000/auth/threads/connect`
